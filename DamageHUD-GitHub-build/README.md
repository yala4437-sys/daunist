# DamageHUD — Minecraft 1.21.11 (Fabric)

Клиентский HUD для отображения здоровья игрока под прицелом и приблизительного урона обычной/критической атаки.

## Сборка готового JAR через GitHub Actions

1. Создайте пустой репозиторий GitHub.
2. Загрузите **все содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** и выберите **Build DamageHUD**.
4. Нажмите **Run workflow**.
5. После завершения успешного запуска скачайте артефакт `DamageHUD-Minecraft-1.21.11-Fabric`.
6. Внутри скачанного ZIP будет готовый `damagehud-1.0.0.jar` (или файл с соответствующим именем версии).

Для локальной сборки нужны Java 21, Gradle 9.2.1 или совместимее и доступ в интернет для скачивания зависимостей Minecraft/Fabric.

**Важно:** расчёт урона приблизительный; он не может гарантировать фактический урон на серверах с нестандартными настройками, эффектами или плагинами.
